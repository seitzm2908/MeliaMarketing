# 🎯 Melia Marketing - KI Content Creation System

**Melia** ist eine spezialisierte KI Marketing-Assistentin, die täglich um 6:00 Uhr automatisiert hochwertigen, innovativen Content für die Immobilienwirtschaft erstellt.

## 📋 Workflow

### Täglicher Prozess (6:00 Uhr)
1. **Research** 🔍
   - Webrecherche zu aktuellen Immobilienenwicklungen
   - Markttrends & Datensammlung
   - Inspirierende Ansätze außerhalb der Branche

2. **Content Creation** ✨
   - Social Media Posts (LinkedIn, Instagram, TikTok)
   - Video-Konzepte
   - Analysen & Reports
   - Sonstiges (Case Studies, Infografiken, etc.)

3. **Positionierung** 🎨
   - Unique Angle: Weg vom klassischen Immobilien-Marketing
   - Zielgruppe: Moderne Investoren & Tech-savvy Käufer
   - Tone: Innovativ, datengetrieben, inspirierend

4. **Task-Verwaltung** 📌
   - Aufgaben als GitHub Issues anlegen
   - Status-Tracking
   - Publikationsplanung

## 🏷️ Issue Labels

**Content-Typen:**
- `posts` - Social Media Posts
- `videos` - Video-Konzepte
- `analysen` - Marktanalysen
- `sonstiges` - Sonstiges/Spezial-Content

**Status:**
- `research` - Recherche-Phase
- `in-progress` - Wird bearbeitet
- `review` - Zur Überprüfung
- `published` - Veröffentlicht

**Stadt-spezifische Labels:**

## 🔗 Claude-GitHub Integration

Melia nutzt folgende Prozesse:

### 1. Issues erstellen
```
Claude → GitHub API → Neue Issue als Task (mit Stadt-Label)
```

### 2. Stadt-spezifische Research
```
Melia recherchiert Stadt-Daten → Daten in Issue dokumentieren → Status aktualisieren
```

### 3. Content-Entwürfe pro Stadt
```
Content-Erstellung (Stadt) → Als GitHub-File speichern → Review
```

### 4. Publishing-Workflow
```
Ready → Label "review" → Genehmigung → Label "published"
```
